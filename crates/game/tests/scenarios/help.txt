# Help, man, ?, and suggestions for typos.
The Relay
A crowded public node.
Routes: market, back-room, bazaar
Files: motd.txt, rules.txt
> ?
Here you can use: look, ls, go, read, download, inventory, status, stash, grep, echo, say, channels, join, leave, who, news, crew, tell, ignore, block, report, help
> help go
go <place>
Move to a host through a route.
Other names: cd, connect, ssh
Example: go market
> man pipes
Pipelines
Join commands with | to send the items of one command to the next.
Only the last command shows its output.
Programs in one pipeline share one setup cycle and one connection.
Example: ls | grep txt | read
> help | grep rig
read <file>       Show the text of a file here or on your rig.
download <file>   Copy a file from this host to your rig.
upload <file>     Copy a file from your rig to this host in a target network.
inventory         Show the files on your rig.
buy <item>        Buy a program or a rig upgrade at a shop.
lots              Show the lots of the police auction: the data, hardware, and programs from the rigs of burned handles.
probe <ice|file>  Find the weak point of an ICE, or find out if a file is a honeypot. In a darknet, it also shows the rig of a handle.
crack <ice>       Attack an ICE. At zero integrity, the ICE breaks. In a darknet, it also attacks the rig of a handle.
echo <text> [> script] Show the text. With > or >>, write it to a script on your rig. > replaces the script, and >> adds a line.
rm <file>         Delete a script from your rig, or a file on this host in a target network.
sh <script> [words] Run a script from your rig. It runs one command on each tick and uses 1 GB of RAM. The words go into $1 to $9.
ps                Show the script that runs on your rig.
kill              Stop the script that runs on your rig.
