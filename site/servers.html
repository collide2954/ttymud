Servers

This page shows the public list of servers. The client has the same list, so you can connect to a server on the list by its name. Then the client compares the key of the server with the key on the list.

{{servers}}

Connect with the key

A client knows only the servers that were on the list when someone built it. To connect to a newer server, use its address and its key:

ttymud connect ADDRESS --key KEY

The client compares the key of the server with the key that you give. Then it keeps the key for the next connections.

Add your server

To add your server to the list, change the file servers.ini in a pull request. The operator guide tells you how.
