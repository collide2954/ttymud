Free and open source

A multiplayer hacker game for the terminal

You are a hacker in a near-future city. You take contracts, hack into corporate networks, and steal data.

Security software and analysts try to trace you. If they trace you too often, your handle burns, and you start again with a new identity.

Try it Read the player guide

The game

TTYmud is a MUD, a multi-user dungeon. The networks are the dungeons, and the hostile security software is the monster.

Hack in real time

ICE shows its next action and the ticks that are left. Probe, crack, and scrub before the trace gets to 100%.

A city that reacts

The noise of all players raises the alert level of each corporation. Analysts read your logs, and companies patch the exploits that players use too much.

Jobs from fixers

Fixers post new jobs each day. The server makes a new network for each job, so no two runs are the same.

Crews and heists

Make a crew of up to 4 handles. Crewmates share one copy of a target and break into a vault together.

Heat and burns

Each trace adds heat. At heat 5, your handle burns. Your account keeps its know-how and its stash for the next handle.

Programs and money

Compile stronger versions of your programs from blueprints. Sell stolen data to the fence, and bid at the police auction.

Fights by consent

Challenge a handle to a duel in the arena, or play capture the flag against a different crew. A fight gives no heat, and your rig comes back as it was.

The darknet

Under the Night Market, the fence pays more and the blueprints are better. But there, other handles can crash your rig and take your data.

Scripts on your rig

Write a script with echo, as in a shell, and run it with sh. It runs one command on each tick and uses the RAM and the cycles of your rig.

Linked cities

Each server is a city. Operators can make links between their cities. The longline channel reaches the players of all linked cities, and each city sends its news to the others.

Play over SSH

On a server with an SSH port, a normal SSH client is enough. Your SSH key is your account, and you get the same HUD as the client.

Made for the terminal

  • Easy to learn. If you know a shell, you know how to play. If you do not know a shell, the game teaches you.
  • Hard to predict. Targets change on each run. Corporations patch the exploits that players use too much.
  • Fair danger. Hostile software shows its next action before it acts.
  • All terminals. Line mode works on all terminals and with screen readers. Better terminals get status bars, panes, and color.
  • Safe by default. TTYmud encrypts all traffic. Your account is a key, not a password. The server removes terminal escape codes from all player text.
  • Easy to host. One binary runs a city. The server keeps its data in plain text files.
  • Light. TTYmud has very few dependencies.

Play

Try it alone

Install Rust with rustup. Then get the code and walk Port Ostra alone, without a network:

git clone https://github.com/collide2954/ttymud
cd ttymud
cargo run -p ttymud-server -- play

Type a handle, and then select a starter kit. Type help to see the commands, and contract to see your first job.

Connect to a server

Build the client. Then connect to a server on the server list by its name, or to the address of a different server:

cargo build --release -p ttymud
target/release/ttymud servers
target/release/ttymud connect ostra.example.net

At the first start, the client makes your identity key. For a server on the list, the client checks the key of the server. For a different server, compare its fingerprint with the fingerprint that its operator publishes.

If the server has an SSH port, you can also connect with SSH and your SSH key:

ssh -p 7332 ostra.example.net

The player guide tells you how to play, from the first connection to crews and heists.

Host a city

One binary runs a city, and the server keeps its data in plain text files. Use these commands to make a data directory and to start the server:

cargo build --release -p ttymud-server
target/release/ttymud-server init ostra-data
target/release/ttymud-server run ostra-data

The server listens on port 7331. The operator guide tells you about the server key, moderators, backups, and the game data.

Status

TTYmud is in early development. You can run a server and play Port Ostra with other players over an encrypted connection.
