# Security policy

## Report a security problem

Do not report a security problem in a public issue. Use a private report:

1. Open the [Security tab](https://github.com/collide2954/ttymud/security) of the repository.
2. Select **Report a vulnerability**.
3. Write the problem and the steps that make it occur.

Only you and the maintainers can see the report. The maintainers reply to you and work with you on a fix. When the fix is ready, the maintainers publish an advisory.

## Supported versions

TTYmud has no release yet. The maintainers fix security problems on the `main` branch.

## Examples of security problems

- A way to read or change the traffic between a client and a server.
- A way to use the account of a different person.
- Text from one player that changes the terminal of a different player.
- A way to stop a server or to make it too slow for other players.
